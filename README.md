# A股每日买入计划 · iPhone 可安装客户端

一个**纯前端 PWA**（可添加到 iPhone 主屏幕的网页应用）＋ Windows 一键启动器。
每天用真实行情算出「今天买什么、买多少、什么价、什么时候买、什么时候卖」，并生成可直接照抄到同花顺的下单清单。

**零后端、零第三方依赖、零 CDN、零签名、零账号、零费用。**
所有数据与计算都在你自己的手机/电脑里完成，不上传任何信息。

## 三、尾盘 5 分钟怎么用（核心流程）

A 股 **14:57–15:00 是收盘集合竞价**，14:55–14:57 是连续竞价。
所以「尾盘 5 分钟」= **14:55–15:00**。

| 时刻 | App 做什么 | 你做什么 |
|---|---|---|
| 盘中随时 | 打开就能看当前候选，数据实时 | 心里有个数 |
| **14:50** | 自动进入**尾盘模式**，顶部出现倒计时条，刷新收紧到每 15 秒 | 打开 App |
| 14:50–14:55 | 每 15 秒刷一次候选池行情并全量重算，列表实时跳动 | 观察，不动手 |
| **14:55** | **锁定最终清单**（3–5 只），价格和股数定格 | 点「推荐」Tab，准备下单 |
| 14:57–15:00 | 界面显示「待执行」 | **在同花顺下单**（见第五节） |
| 15:00 后 | 自动归档当日计划 | 收盘 |

> 手机端也可以在 14:50 之前手动点右上角「刷新」按钮做全量刷新，效果一样。
> 如果当天你错过了 14:55，清单仍然有效到收盘，只是价格会随行情微调。

## 四、三条下单路径（A / B / C）

App **不会**直接操作你的证券账户，也**不碰**同花顺的账号。它给你三种执行方式：

### 路径 A — 条件单参数表（推荐，设一次就不用盯盘）

在「推荐」Tab 点「条件单参数」，会弹出每只股票的完整参数表，逐项对应同花顺「条件单 / 智能交易」的输入框：

| 字段 | 值（示例） |
|---|---|
| 证券代码 / 名称 | 300494 盛天网络 |
| 触发条件 | 价格 ≤ 9.99 |
| 委托价格 | 9.99 |
| 委托数量 | 600 股 |
| 有效期 | 当日 |
| 止损单 | 价格 ≤ 9.19 触发市价卖出 |

设置路径：**同花顺 App → 交易 → 条件单 → 新建条件单 → 选择该股票 → 按上表填写触发价与委托量**

> 条件单由**券商服务器**监控触发，即使 App 关掉也会执行。这也是「自动买入卖出」在合规前提下最接近的做法。

### 路径 B — 一键复制清单（兜底，最快）

点「复制全部下单清单」，得到纯文本，粘到备忘录/微信，然后尾盘照单逐只手动下单：

```
【2026-10-26 尾盘计划｜中性档 60%｜本金 50000】
1. 300494 盛天网络  买入 600 股 @9.99  止损 9.19  止盈① 10.59  止盈② 11.19
2. 002368 太极股份  买入 300 股 @15.34 止损 14.12 止盈① 16.26  止盈② 17.18
...
合计占用 24,408 元（48.8%），剩余现金 25,592 元
提示：尾盘 14:55–15:00 挂单；价格可挂高 0.5%~1% 确保成交。
```

### 路径 C — 内置模拟盘（零风险练手）

「持仓」Tab 手动录入成交价/数量，App 会自动盯市、算盈亏、算胜率、画净值曲线，触及止损止盈时高亮提醒。
**这是本地记账，不会真的下单。**

### 明确不做：UI 自动化自动下单

不提供 ADB / Appium / 无障碍服务操控同花顺 App 的功能，原因：

1. 违反同花顺用户协议，**有封号风险**
2. 证监会《程序化交易管理规定》（2025-07-07 生效）要求程序化交易向券商报告
3. 手机 App 界面改版即失效，极不稳定

## 五、选股逻辑（它凭什么推荐这几只）

整条链路 **基础过滤 11 道 → 主线筛选 → 策略专属门槛 → 因子打分 → 组合约束 → 生成计划**。

> **所有过滤条件都可以自己改**：打开「设置 → 过滤条件设置」，每一条都能单独开关、改阈值、改比较运算符，
> 还能自己添加全新条件（如「毛利率 ≥ 20%」「市盈率 ≤ 50」）；五个策略各有独立的快照门槛与因子门槛。
> 详见 [第六章：自定义过滤条件](#六自定义过滤条件每一条都能开关和编辑)。

### 第 1 步：股票池 11 道过滤（约 5400 只 → 1100~1800 只）

| # | 过滤条件 | 说明 |
|---|---|---|
| 1 | 剔除停牌 | 无报价的直接跳过（必需，不可关闭） |
| 2 | **剔除 ST / 退市** | 名称含 `ST`、`退`、`*` |
| 3 | 价格 > 2 元 | 剔除低价垃圾股 |
| 4 | **市值 20 亿 ~ 800 亿** | 总市值口径，区间可改 |
| 5 | 成交额 ≥ 1 亿 | 保证流动性 |
| 6 | 换手率 ≥ 0.5% | 剔除死水股 |
| 7 | 剔除当日涨停 / 一字板 | 买不进去 |
| 8 | 剔除跌停 | 流动性差，通常有雷 |
| 9 | **剔除创业板（300/301 开头）** | 默认开启，可一键关闭 |
| 10 | **一手成本 ≤ 单只预算** | 5 万本金下买不起的直接排除（科创板按 200 股一手算） |
| 11 | 仅保留沪深 A 股 | 代码以 `6` / `0` / `3` 开头 |

> 第 10 条很关键：不过滤的话，TOP5 里会出现 91 元、147 元的票，算出来股数是 0，实际根本买不了。
>
> 第 9 条（排除创业板）是默认行为，但**只是一条可关闭的规则**——它在「设置 → 过滤条件设置 → 基础过滤」里，
> 点一下开关就关掉了，不需要改代码。

### 第 2 步：近一周主线情绪（对应你的要求）

**板块清洗**：概念 516 个 + 行业 496 个 = 1012 个板块，先用 50 多个噪音词剔除伪板块（`昨日`/`连板`/`涨停`/`融资融券`/`MSCI`/`预增`/`季报`/`破净`/`转债`/`基金`/`大盘`/`超跌` 等），再要求成分家数 ≥ 15 → 剩 **约 660 个有效板块**。

**板块得分**（`f109` 是 5 日涨跌幅，`f160` 是 10 日涨跌幅）：

```
得分 = f109 × 2.0        ← 近一周涨幅，权重最高
     + f3   × 1.0        ← 当日涨幅
     + (上涨家数占比 − 0.5) × 20   ← 板块内广度
     + clip(主力净流入亿 / 5, −3, +3)  ← 资金流向
```

**个股主线分**：用个股的行业 `f100` 与概念串 `f103` 匹配板块名（实测匹配率 **100%**），取最强 3 个板块得分的均值。

**硬门槛**：必须属于**主线 Top20**，且**不在退潮 Top10**。实测约 150–220 只通过。

### 第 3 步：因子横截面打分与四套策略

| 因子 | 含义 | 均衡多因子 | 趋势动量 | 超跌反弹 | 龙头战法 |
|---|---|---|---|---|---|
| `mom20` | 20 日动量 | 20% | 30% | 10% | 10% |
| `trend` | 趋势强度（相对 MA20/MA60 偏离） | 20% | 20% | 10% | 15% |
| `main` | 主线强度 | 20% | 15% | 15% | 5% |
| `mom5` | 5 日动量 | 10% | 15% | 10% | 5% |
| `dd` | 距 60 日高点的回撤 | 10% | 10% | 20%(反向) | 5% |
| `vr` | 量比（今日量 / 5 日均量） | 10% | 10% | 10% | 10% |
| `rsi` | RSI(14) | 5%(反向) | 5%(反向) | 20%(反向) | 5% |
| `atrp` | 波动率 ATR% | 5%(反向) | 5%(反向) | 5%(反向) | 5%(反向) |
| `attention` | 市场关注度（主线排名、主线强度、主力净流入） | - | - | - | **20%** |
| `activity` | 市场活跃度（换手率、成交额、快照量比） | - | - | - | **20%** |
| `leader` | 全市场龙头度（关注度 55% + 活跃度 45%） | - | - | - | 过滤门槛 |

所有因子先做**横截面分位标准化到 0–100**，再加权 → 消除量纲差异。

### 第 3.5 步：每种策略对应专属的股票池过滤明细

整个筛选流程分为清晰的三段，在设置页「股票池过滤明细」中分组呈现：
1. **基础过滤（所有策略共用，11 道）**：剔除停牌、ST/退市、低价、非 20~800 亿、成交额不足 1 亿、死水换手、涨停一字板、跌停、创业板（可选）、单手成本超预算、非沪深 A 股。
2. **主线门槛（所有策略共用）**：所属板块必须进入最近一周主线 Top20 且非退潮。
3. **策略专属门槛（快照级初筛 + K 线因子门槛）**：
   - **均衡多因子**：换手 1%~18%、量比 ≥ 0.8、市值 ≤ 600 亿；20 日动量 > -10%、均线多头 ≥ 1/3、ATR% ≤ 12%。
   - **趋势动量**：成交额 ≥ 2 亿、换手 ≥ 2%、量比 ≥ 1.0、当日红盘；均线多头全多头 (3/3)、20 日动量 > 0、回撤 ≤ 18%、RSI ≤ 82。
   - **超跌反弹**：当日跌幅 -8%~+3%、市值 ≤ 300 亿；20 日动量为负、距 60 日高点回撤 ≥ 15%、RSI < 50、ATR% ≤ 15%。
   - **龙头战法**：**必须属于主线 Top10 板块**、成交额 ≥ 2 亿、换手 ≥ 2%；**全市场龙头度 ≥ 60**、均线全多头 (3/3)、20 日动量 > 0、量比 ≥ 1.0、回撤 ≤ 15%。评分分别以 20% 权重纳入市场关注度和活跃度。
   - *（注：极端行情下策略门槛自带保底放宽机制，确保不会因门槛过严而空池）*

> 以上每一条都只是**默认值**，不是写死的代码。在「设置 → 过滤条件设置」里可以逐条开关、改阈值、改运算符，
> 也可以自己加条件。详见下一章。

设置页可随时切换四种策略：**均衡多因子 / 趋势动量 / 超跌反弹 / 龙头战法**，并提供「各策略初筛候选数对比」小表。

### 第 4 步：组合约束

- 同一行业（`f100`）最多 2 只
- 同一主线板块最多 2 只
- 只数受大盘档位限制

### 第 5 步：大盘环境决定仓位（对应「结合当日市场情况」）

四个维度打分 → 0–100 总分 → 四档：

| 维度 | 权重 | 看什么 |
|---|---|---|
| 趋势 | 30% | 上证收盘 vs MA20 / MA60，MA20 vs MA60，5 日动量 |
| 广度 | 25% | 全市场上涨家数占比 |
| 情绪 | 25% | 涨停数 vs 跌停数，最高连板高度 |
| 量能 | 20% | 两市成交额 vs 20 日均额 |

| 总分 | 档位 | 建议仓位 | 推荐只数 | 5 万本金 → 单只预算 |
|---|---|---|---|---|
| ≥ 70 | 进攻 | 80% | 5 只 | 8,000 元 |
| 50–70 | **中性** | **60%** | **5 只** | **6,000 元** |
| 30–50 | 防守 | 35% | 4 只 | 4,375 元 |
| < 30 | 冰点 | 20% | 3 只 | 3,333 元 |

### 第 6 步：生成买卖参数

```
涨停幅度    300/301/688 开头 = 20%，其余 = 10%
委托价      min(现价 × 1.008, 涨停价 × 0.995)   ← 挂高 0.8% 确保成交
股数        floor(单只预算 / (委托价 × 100)) × 100    ← 100 股一手
止损价      min(委托价 × 0.95, 近5日最低 × 0.98, 委托价 − ATR×2)
            再夹在 [委托价 × 0.92, 委托价 × 0.985] 之间   ← 最大亏 8%
止盈①      委托价 × 1.06   （卖一半）
止盈②      委托价 × 1.12   （清仓）
持有周期    3–5 个交易日
费用        佣金 max(5, 金额×0.00025) + 过户费 金额×0.00001
            卖出另加印花税 金额×0.0005
```

## 六、自定义过滤条件（每一条都能开关和编辑）

打开 **设置 → 过滤条件设置**，你会看到当前所有过滤条件，按四组排列：

| 分组 | 内容 |
|---|---|
| **基础过滤（所有策略共用）** | 停牌、ST/退市、价格、市值区间、成交额、换手率、涨停、跌停、创业板、一手成本、沪深 A 股 |
| **主线门槛（所有策略共用）** | 必须属于主线 Top N（默认 20）、剔除退潮板块（默认尾部 10 个） |
| **〈当前策略〉· 快照门槛** | 只用实时行情就能判断的条件 |
| **〈当前策略〉· 因子门槛** | 需要日 K 线才能算的条件（动量、回撤、均线多头、龙头度…） |

每一行都能做四件事：

1. **开关** —— 点左侧滑块即关闭该条件（关闭的行会变灰）。停牌过滤是**必需项**，锁定不可关（没有报价就算不出买入价）。
2. **改阈值** —— 直接改输入框，失焦即生效。
3. **改运算符** —— 下拉可切换 `≥` `≤` `>` `<` `介于(a~b)`，文本字段还能用 `包含` / `不包含` / `开头是` / `结尾是`。
4. **添加自定义条件** —— 「＋ 添加自定义条件」按钮，先选字段（快照字段 / K线因子 / 文本字段），再选运算符和数值。

**五个策略互相独立**：卡片顶部有策略下拉，切换后编辑的是那个策略的专属门槛；当前策略名后会标注「（当前）」。
顶部还有「**恢复默认**」按钮，一键把所有条件还原成出厂设置。

**改动即时生效**：不需要重新联网拉数据。引擎会拿本地缓存的快照直接重算股票池与因子（毫秒级），
几秒内就能在「今日计划」看到新的推荐结果。

### 可用于自定义条件的字段

| 分组 | 字段 |
|---|---|
| 快照字段（实时行情，无需 K 线） | 价格、涨跌幅、换手率、量比、成交额(亿)、总市值(亿)、流通市值(亿)、市盈率、市净率、主力净流入(亿)、主线分、主线排名 |
| K线因子（需日 K 线） | 20日动量、5日动量、60日回撤幅度、趋势强度、RSI、波动率ATR、均线多头数、量比(K线)、板块龙头度 |
| 文本字段 | 名称、代码、所属行业、概念、市场 |

几个实用例子：

- **只想买大票**：基础过滤里把「总市值」改成 `介于 200 ~ 800 亿`。
- **不想要创业板**：基础过滤里关掉「排除创业板」（默认是开着的）。
- **更严格的价值筛选**：加一条自定义条件「市盈率 ≤ 30」。
- **规避高位股**：当前策略的因子门槛里改「60日回撤幅度 ≤ 15%」。
- **只看最强主线**：主线门槛里把 Top N 改成 5。

> 技术细节：过滤条件在代码里是**可序列化的声明式规则**（`{id, on, field, op, value, strict}`），
> 存在浏览器本地 IndexedDB 的 `settings.filterConfig` 里（默认 `null` 表示全部用代码默认值）。
> 字段缺失时一律**放行**（fail-open），只有标记 `strict` 的条件（价格 >2 元、均线全多头 3/3）才会拦截。

## 七、数据从哪来

东方财富公开行情接口（浏览器直接跨域调用，无需代理）：

| 用途 | 接口 | 实测 |
|---|---|---|
| 全市场快照 | `push2test.eastmoney.com/api/qt/clist/get` | 5563 只 / 56 页 / 1.65 MB / 1.1s |
| 概念板块 | 同上，`fs=m:90+t:3` | 516 个 / 6 页 |
| 行业板块 | 同上，`fs=m:90+t:2` | 496 个 / 5 页 |
| 候选池实时刷新 | `ulist.np/get` | 每批 100 个代码 / 13 批 / 192 KB / 134 ms |
| 日 K 线 | `3.push2his.eastmoney.com` 等 4 个 `push2his` 镜像轮转 | 每只 250 根（完整一年） |
| 涨跌停池 | `push2ex.eastmoney.com/getTopicZTPool` | 当日 |
| 服务器时间校准 | `trends2/get` | 逐分钟，防手机时钟偏差 |

> **为什么要分两套主机**：东财的行情快照（`clist`/`ulist`）与日 K 线（`kline`）由不同集群提供。
> 实测 `push2his` 系主机对 `clist` 全部失败、`push2test` 的 `kline` 数据窗口残缺
> （同一只股票只回 73~116 根且中间有 28~57 天空档，会让 MA60 与 60 日回撤算错）。
> 因此快照走 `push2test` 池、日 K 走 `push2his` 池，且每根 K 线都做「根数 ≥100 且无 >15 天空档」的质量校验，
> 不合格的宁可不入库也不参与计算。

**三档刷新策略**（省流量、省电）：

| 档位 | 触发 | 流量 | 耗时 |
|---|---|---|---|
| 冷启动 | 首次 / 跨日首次打开 | ≈2.3 MB | ≈5 秒 |
| 尾盘刷新 | 14:50–15:00 每 15 秒 | ≈150 KB | ≈0.3 秒 |
| K 线增量 | 每日盘后 | 0（用快照合成当日 bar） | ~0 |

> 数据缓存在手机本地 IndexedDB（约 2–4 MB），第二次打开走缓存 + 增量，很快。

> 东财限流属环境抖动，不是产品缺陷；产品端同样对每只 K 线做 `catch` 容错。

## 十一、常见问题

**Q：双击 `启动.bat` 一闪就没了？**
A：说明没找到 Node.js 或 Python。装一个 Node.js（https://nodejs.org/zh-cn/download 下载 `.msi` 双击安装）即可，装完重开。

**Q：手机扫码打不开？**
1. 确认手机和电脑连的是**同一个 WiFi**（不是 4G/5G）
2. 确认黑窗口还开着
3. 在手机浏览器手动输入 `http://192.168.x.x:8765/`（把 `192.168.x.x` 换成黑窗口里显示的地址）
4. Windows 防火墙弹窗时选「允许访问」

**Q：端口 8765 被占用？**
A：启动器会自动顺延到 8766、8767…，看黑窗口打印的实际端口号即可。也可以手动指定：`启动.bat --port 9000`

**Q：添加到主屏幕后还是显示地址栏？**
A：必须用 **Safari** 打开再添加。微信、QQ、Chrome for iOS 添加出来的都不是独立 App。

**Q：数据是实时的吗？**
A：是。全部来自东方财富公开行情接口，交易时段每 15 秒刷新。K 线历史走本地缓存。

**Q：第一次打开很慢 / 提示「补拉 K 线」？**
A：首次打开需要拉全市场快照（56 页）+ 180 只股票的日 K 线，约 5~10 秒。之后走 IndexedDB 缓存，秒开。
日 K 线的主机成功率约 55%，程序会自动在 4 个镜像间轮转重试（单只最多 5 次），综合成功率约 96%，
偶尔有少数股票拉不到 K 线不影响推荐（它们会被跳过，不会用残缺数据算 MA60）。

**Q：以前打开过，现在界面还是旧的？**
A：已修。Service Worker 改为**网络优先**策略，并升级了版本号（`stock-advisor-v1.3.0`）；
旧版缓存会在下次打开时自动淘汰。若仍异常，iOS 上把主屏图标删掉重新添加一次即可。

**Q：为什么推荐的股票我买不了？**
A：两个可能：① 一手成本超过你的单只预算（降低本金设置会导致这个）② 该股已涨停封死。App 已经过滤了这两种情况，如果仍遇到，说明盘中价格已变化，重新刷新即可。

**Q：能自动下单吗？**
A：不能，也不建议。见第四节「明确不做」。用**条件单（路径 A）**是在合规前提下最接近自动化的方案。

**Q：数据会泄露吗？**
A：不会。没有后端服务器，没有账号，本金和持仓只存在你手机的 IndexedDB 里。唯一的对外请求是向东财取行情。

**Q：手机上数据太大占空间？**
A：约 2–4 MB，远低于浏览器配额。「设置 → 数据管理 → 清空缓存」可随时清理。
