# 后续开发路线与已知限制（Backlog）

> 本文件记录**还差什么**和**哪里会痛**，方便接手的人快速定位。
> 完成一项就移到 `CHANGELOG.md` 并在版本号上体现。

## 一、已知限制（不是 bug，是当前设计边界）

| # | 限制 | 影响 | 可能的解法 |
|---|---|---|---|
| L1 | 局域网 HTTP 下 Service Worker 不注册 | 手机端无离线缓存、无法获得完整 PWA 体验（主屏图标仍可添加） | 提供 HTTPS 托管方案（已有 README 第九节）；或本机自签证书 + iPhone 信任 |
| L2 | 回测存在幸存者偏差 | 股票池取自今日快照，历史已退市的票不在池内，收益偏乐观 | 引入历史退市名单；或改用"当期可交易全集"快照 |
| L3 | 回测未计入滑点与冲击成本 | 小盘股真实成交价会偏离 | 按成交额分档加滑点模型 |
| L4 | 依赖东财公开接口，**无 SLA** | 会被限流（实测 `push2his` 连续失败数百次），字段可能变更 | 已是多镜像轮转 + 重试 + 降级；可考虑接入第二数据源做交叉校验 |
| L5 | 非交易时段行情字段全为 `"-"` | 盘前打开 App 股票池为 0，看起来像坏了 | 已在自测里识别该时段；产品端可加"当前非交易时段，显示上一交易日计划"的显式提示 |
| L6 | 下单仍需人工在券商 App 确认 | 不做 ADB/无障碍自动化（有封号与合规风险，已明确排除） | 保持现状。A 条件单 / B 复制清单 / C 模拟盘三条路径已覆盖 |
| L7 | 无账户体系、无多设备同步 | 数据只在本机浏览器 IndexedDB | 如需同步可加导出/导入 JSON |
| L8 | 单一市场（沪深 A 股） | 不含北交所、港股、ETF | 扩展 `FS_ALL` 与 `secidOf` 映射 |

## 二、优先级建议

### P0 — 影响日常可用性

- [ ] **盘前/盘后显式提示**：当前只在自测里识别"行情字段为 `-`"，产品界面应明确显示
      「当前非交易时段（或集合竞价前），以下为上一交易日计划」，避免用户以为坏了。
- [ ] **数据新鲜度标识**：顶部显示"数据更新于 HH:MM:SS"，超过 N 分钟变黄提醒刷新。
      尾盘时段尤其需要（用户可能依赖一个 20 分钟前的计划下单）。
- [ ] **失败可诊断**：接口连续失败时，界面给出「东财接口暂不可用（已重试 N 次）」而不是空白。

### P1 — 提升选股质量

- [ ] **因子有效性回测**：`backtest.js` 已有 `runBacktestMatrix`，但界面上只暴露单策略回测。
      把多策略对比表做出来，让用户自己看哪个策略近期有效。
- [ ] **行业轮动维度**：当前行业只用于"组合约束"（每行业 ≤2 只），未进入打分。
      可加"行业近 5 日强度"因子。
- [ ] **主力资金连续性**：现在只用了当日净流入，可加 3/5 日累计。
- [ ] **可配置的止损止盈**：`plan.js` 的 `calcStop` / `calcBid` 是固定规则，应开放参数。

### P2 — 工程与体验

- [ ] **UI 自动化测试覆盖交互**：当前 E2E 只验证渲染与弹层，未覆盖"切换策略后推荐是否变化"。
- [ ] **设置导入/导出**：JSON 导出，便于换设备与备份。
- [ ] **PWA 更新提示**：`sw.js` 已实现 `SKIP_WAITING` + `controllerchange` 自动 reload，
      但用户无感知。可加一个"发现新版本，点此更新"的 toast。
- [ ] **图表交互**：K 线目前是静态渲染，可加长按十字光标。

### P3 — 可选扩展

- [ ] 自选股 / 关注列表
- [ ] 交易日志导出（CSV）
- [ ] 多账户模拟盘
- [ ] 移动端手势（左右滑动切 Tab）

## 三、技术债

| # | 债务 | 说明 | 建议 |
|---|---|---|---|
| D1 | `main.js` 667 行 | 编排 + 状态 + 路由 + 尾盘 + 弹层全在一个文件 | 拆出 `router.js` / `tail.js` / `sheet.js`，`main.js` 只做装配 |
| D2 | `selftest.mjs` 58 KB | 单文件 1000+ 行，断言与工具混在一起 | 按模块拆成 `tools/tests/*.mjs` |
| D3 | `server.mjs` 与 `server.py` 双实现 | 功能需手工保持同步 | 明确以 `server.mjs` 为准，`server.py` 只保证"能跑起来" |
| D4 | 无 TypeScript / 无类型检查 | 契约靠文档与自测保证 | 可加 JSDoc `@typedef`，至少让编辑器能提示 |
| D5 | 断言项数随上游浮动 | 好处是误报少，坏处是"跳过了什么"容易被忽略 | 套件已打印跳过原因；可在报告里单列"跳过清单" |

## 四、绝不能做的事（踩过的坑 / 合规红线）

1. **不要用 `push2test` 拿 K 线** —— 只有 73~116 根且带大缺口，因子会全错。
2. **不要把 SW 改成缓存优先** —— 用户装到主屏后会永远跑旧 JS，改 bug 到不了他手上。
3. **不要用 ADB / 无障碍服务自动操作券商 App** —— 违反券商协议，有封号风险。
4. **不要删除回测的风险提示** —— 幸存者偏差 + 未计成本，不提示会误导。
5. **改任何 `web/` 下的预缓存文件后必须 bump `sw.js` 的 `VERSION`**，否则用户端不更新。
6. **不要用 PowerShell 文本管道改写源码文件** —— PS 5.1 会把无 BOM 的 UTF-8 当 GBK，
   产生乱码、加 BOM、吞换行。用编辑器或 `[System.IO.File]::WriteAllText` + `UTF8Encoding($false)`。
